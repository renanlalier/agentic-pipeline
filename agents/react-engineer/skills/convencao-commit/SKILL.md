# Convenção de commit e branch

## Branch
`agentic/<execution_id>` — sempre.

## Commit
`feat: <papel> para #<sub_issue> (exec <execution_id>)`.

## Pull request
Sempre em draft, sempre com `Closes #<sub_issue>`.
